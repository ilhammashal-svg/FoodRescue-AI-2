# FoodRescue AI — منقذ فائض الطعام

نظام يسجّل فائض الطعام لدى المؤسسات الغذائية (مطاعم، مقاصف، فنادق، جامعات) ويصنّفه في ثلاثة مسارات — **توزيع بشري** عبر الجمعيات وبنوك الطعام، **سماد**، **إتلاف آمن** — ويطابقه بالجهة المستلمة المناسبة، مع **مراجعة بشرية إلزامية** لكل قرار.

## المحتوى
`foodrescue-ai-maestro/` — Plugin لـ Claude يشغّل أوركسترا من 17 وكيلًا أسبوعيًا:

| المرحلة | الوكلاء |
|---|---|
| 0 | حارس المدخلات (قراءة الداشبورد) |
| 1 | سكرتير الاجتماع · محلل البيانات · راصد السوق |
| 2 | مسؤول الولاء · موزّع المهام (monday.com) |
| 3 | مصمم البوستات (Canva) · معدّ العرض (Gamma) · وكيل الفيديو (HeyGen) |
| 4 | أمين الأرشيف (Google Drive) · مصمم التطبيق (Claude Design + Netlify) |
| 5 | مُجدول الاجتماعات (Google Calendar) · منسق البريد (Gmail) |
| 6 | حارس المدخلات (كتابة النتيجة) · أمين المستودع (GitHub) |
| دائمًا | لوحة القيادة · واجهة المخرجات · مضيف الوكلاء |

## الأوامر
- `/foodrescue-ai-maestro:start-orchestra` — إعداد الداشبورد مرة واحدة
- `/foodrescue-ai-maestro:rehearsal` — بروفة على بيانات وهمية بلا أي إرسال
- `/foodrescue-ai-maestro:perform` — التشغيل الأسبوعي الحقيقي
- `/foodrescue-ai-maestro:add-agent` — إضافة وكيل جديد

## التثبيت
ضغط مجلد `foodrescue-ai-maestro` كملف zip ورفعه في Claude ← Customize ← Plugins.

## الخصوصية
لا بيانات حقيقية في هذا المستودع: الإيميلات والروابط ومعرّفات الحسابات أُزيلت، وبيانات `workspace-template/examples/rehearsal` وهمية بالكامل. لا تُرفع مفاتيح API أو أرقام هواتف هنا أبدًا.

## سجل النسخ
وكيل «أمين المستودع» يضيف commit جديدًا بعد كل تشغيل أسبوعي وبعد أي تعديل على الوكلاء؛ كل نسخة سابقة محفوظة في History، ولا يُحذف أي ملف. مخرجات كل تشغيل (الملخص وموجز السوق) في `runs/<التاريخ>/`، وسجل التغييرات في `CHANGELOG.md`.
