# /start-orchestra

اقرأ `MAESTRO.md` و`shared/data-contract.md`.

1. إن لم يوجد مجلد العمل: انسخ `workspace-template/` إلى مجلد الشركة `FoodRescueAI/` (لا كتابة فوق موجود).
2. اقرأ ملف المشروع ($ARGUMENTS أو آخر docx مرفق) واستخرج: الاسم، المنتج، القطاعات المستهدفة، الأهداف، المدخلات، الجهات، الضوابط.
3. شغّل `maestro-control-panel` → الداشبورد + البذور. القيم الناقصة تُملأ بالافتراضات الواردة في `ASSUMPTIONS.md` وتُكتب في `config/assumptions`.
4. تحقّق من الموصلات المتاحة (Drive، monday، Canva، Gamma، HyperFrames، Calendar، Gmail، Perplexity). الغائب يُسجّل في `config/assumptions` بعبارة «الوكيل X سيتخطى حتى يُوصل Y».
5. اطبع: رابط الداشبورد، عدد الوكلاء المفعّلين، الموصلات الغائبة، و«أدخلي الإيميلات وارفعي ملفات الأسبوع ثم اضغطي (جاهز للتشغيل)».

سطر واحد بعد كل خطوة.
